03 / Method

Three loops. Every product.

01

Model the trust

Map identity, sessions, APIs, cloud roles, and any model the product treats as benign. Isolated bugs are symptoms. The path is the finding.

02

Spend the trust

Abuse the intended path. Skip the exploit catalog until a control actually has to fail.

Prove it, then close it

Write the attack path so a builder can reproduce it. Fix is the only close.
