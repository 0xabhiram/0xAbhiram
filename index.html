TM-03 · Method

Three loops.
Every product.

01

Model the trust

Map identity, sessions, APIs, cloud roles, and any model/tool the product treats as benign. Isolated bugs are symptoms. The path is the finding.

02

Spend the trust

Abuse the intended path. Skip the exploit catalog until a control actually has to fail. If it yields without resistance, the design already lost.

03

Prove it, then close it

Write the attack path so a builder can reproduce it. Severity is impact plus reach, not a scanner score. Fix is the only close.
